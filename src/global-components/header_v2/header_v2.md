# Welcome to Beaverlab Page Builder
## Header V2

Attenzione questo non è un componente del builder. Prendere i file e sostituirli con quelli del progetto

Il compontente è la base dell' header del progetto Praxi.Praxi.

è un header con menu con comportamento responsive.
Il menu è su 3 livelli.
Al primo livello è associato un titolo e descrizione
Al secondo livello è associata un'immagine
Il terzo livello ha sempre come prima voce il link al relativo padre di secondo livello.(sottolineato e maiuscolo)

Importare il campo acf Custom Menu che gestisce le immagini
